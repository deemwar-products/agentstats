How a card gets created

  
From "Sign in" to a shareable card

  

    
1 · Sign inGitHub App, read-only contents + metadata + email. Go container, /auth/*

    
2 · QueueJob row in D1, fair queue, position shown. Go job queue

    
3 · CountBare-clone each repo, git log --numstat, your emails only, apply exclusion rules. Go analyzer

    
4 · RenderSVG from Go templates; PNG with resvg. Badges, cards, og.png. Go container

    
5 · ServeUpload to R2 (S3 API). The Worker streams it and the edge caches it; badges never wake the container. Worker + R2

  

  

    
Stack

      

        
Backend (web, auth, jobs, analysis, render)One Go container

        
Front routerThin Worker (Rust, or plain JS)

        
Profiles, jobs, badgesD1

        
Rendered SVG/PNGR2 agentstats-cards

        
History + global statsIceberg on R2 + DuckDB

        
UIServer-rendered HTML + CSS + htmx. No TypeScript
