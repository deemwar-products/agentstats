# 08 — Deploy

## Repo layout (`deemwar-products/agentstats`, public)

```
worker/        Rust workers-rs crate + wrangler.toml (routes, D1, R2, DO, containers bindings)
analyzer/      Go module: cmd/analyzer (HTTP + CLI), rules.go, render/ (SVG templates), Dockerfile
migrations/    D1 SQL migrations
prototype/     stats.py + expected-muthuishere.json (regression reference)
docs/          architecture/, reference/ images
Taskfile.yml   dev, test, build, deploy
```

## Cloudflare resources (account: Admin@deemwar.com's Account)

| resource | name |
|---|---|
| Worker | `agentstats` |
| Custom domain | `agentstats.deemwar.com` (zone `deemwar.com`) |
| D1 | `agentstats` |
| R2 bucket | `agentstats-cards` + an R2 API token scoped to it |
| Durable Object class | `UserJob` |
| Container | `analyzer` (image built from `analyzer/Dockerfile`: Go binary + git + resvg + fonts) |

Containers need the Workers Paid plan. Confirm it on the account before the first container deploy.

## wrangler.toml (sketch)

```toml
name = "agentstats"
main = "build/worker/shim.mjs"          # generated by worker-build from Rust; no hand-written JS
compatibility_date = "2026-09-01"
routes = [{ pattern = "agentstats.deemwar.com", custom_domain = true }]

[build]
command = "cargo install -q worker-build && worker-build --release"

[[d1_databases]]
binding = "DB"
database_name = "agentstats"

[[r2_buckets]]
binding = "CARDS"
bucket_name = "agentstats-cards"

[[durable_objects.bindings]]
name = "USER_JOB"
class_name = "UserJob"

[[containers]]
class_name = "Analyzer"
image = "../analyzer/Dockerfile"
max_instances = 5
```

## Pipeline

- `task test`: `go test ./...` (rules + regression fixture), `cargo test`, `wrangler dev` smoke.
- GitHub Actions on `main`: test → `wrangler d1 migrations apply` → `wrangler deploy` (builds and pushes the
  container image too). The Cloudflare token lives in repo secrets; the repo is public, so CI runs
  only on pushes to `main`, never on pull requests from forks with secrets.
- Environments: `dev` (workers.dev, separate D1/R2) and `prod` (custom domain).

## Launch checklist

GitHub App created (owner click) → secrets set → D1 migrated → R2 bucket + scoped token → deploy →
run the owner's own profile end-to-end → compare with `prototype/expected-muthuishere.json` → methodology page live.
