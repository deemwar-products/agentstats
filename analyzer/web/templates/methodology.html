Methodology

How the counting works

The single source of truth for these rules is analyzer/rules.go; this page is generated from those same constants.

What counts

  • Author = your verified GitHub emails. Commits are deduped by SHA across every repo and fork (--all --no-merges).
  • Lines = added lines from git log --numstat, code languages only — {{.LangCount}} recognised file extensions.

What is excluded

  • Non-code: {{range $i, $l := .NotCode}}{{if $i}}, {{end}}{{$l}}{{end}} are not counted as code.
  • Per file: a single file adding more than {{.MaxFileAdded}} lines is skipped.
  • Per commit: a commit touching more than {{.MaxCommitFiles}} files or adding more than {{.MaxCommitLines}} lines is dropped whole (bulk import) — and every dropped commit is listed on your card.
  • Paths: dependency, build, output, vendored, generated and lock/minified/asset files are skipped by this pattern: 
    {{.SkipPattern}}

What we can't see

Time in a chat or an agent session never reaches git, and unsigned agent code looks like human code — so the card says at least N% agent-signed, never "N% AI".
