How the counting works

The single source of truth for these rules is analyzer/rules.go; this page mirrors it.

What counts

  • Author = your verified GitHub emails (plus your noreply address). Commits are deduped by SHA across every repo and fork. --all --no-merges.
  • Lines = added lines from git log --numstat, code languages only (by extension).

What is excluded

  • Paths: node_modules/ vendor/ dist/ build/ target/ .next/ coverage/ bower_components/ out/ __pycache__/ Pods/ .gradle/ venv/ .venv/, any *aot/ dir, anything vendored, anything containing generated.
  • Files: lock files, *.min.js|css, *.map, *.snap, *.svg, *.lock, *.csv|tsv|txt|log, *.pb.go, *_pb2.py, *.g.dart.
  • Non-code: JSON, XML, Markdown, YAML, TOML and notebooks are not counted as code.
  • Per file: a single file adding more than 5,000 lines is skipped.
  • Per commit: a commit touching more than 300 files or adding more than 25,000 lines is dropped whole (bulk import) — and every dropped commit is listed on your card.

What we can't see

Time in a chat or an agent session never reaches git, and unsigned agent code looks like human code — so the card says at least N% agent-signed, never "N% AI".
